# PM_skills

Material from my product management sessions.

## Session 1: How to Break Down a Product

- `session 1/deck.html`: the presentation. Open it in a browser and use the arrow keys; press N for speaker notes.
- `session 1/cheatsheet.html`: every concept from the session on one page, with the original source for each.
- `session 1/rca.html`: the take-home RCA assignment (practice case, made-up data).
- `session 1/deck-source/`: the slide source files (one HTML file per slide, shared CSS and the deck index).

Flow: what a PM does, persona and JTBD, what a breakdown is, narrowing, three lenses (business, user, tech), metrics, the fix format, and a worked example on the NST portal.
